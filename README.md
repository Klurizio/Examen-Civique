# Examen civique : QCM d'entraînement (français / 中文)

- **Examen** : 40 questions aléatoires, 45 minutes, corrigé traduit en chinois simplifié.
- **Entraînement** : traduction visible, correction et explication immédiates.
- **Cours** : chaque question avec sa réponse et son explication (FR / 中文), recherche.

## Mise en ligne avec GitHub Pages
1. Sur github.com, créer un dépôt **public**, par exemple `examen-civique`.
2. « Add file » > « Upload files » : envoyer `index.html`, `questions.js` et `README.md` à la racine, puis « Commit changes ».
3. « Settings » > « Pages » > Source : « Deploy from a branch », branche `main`, dossier `/ (root)`, puis « Save ».
4. Après quelques minutes : `https://VOTRE-PSEUDO.github.io/examen-civique/`

## Contenu
- Questions de connaissance : libellés de la liste officielle CSP du ministère de l'Intérieur
  https://formation-civique.interieur.gouv.fr/examen-civique/liste-officielle-des-questions-de-connaissance-csp/
- Réponses, mauvaises réponses, mises en situation, explications et traductions : rédigées avec une IA, **non officielles, à relire**.
- Les listes carte de résident et naturalisation ne sont pas incluses.

Pour corriger une question, modifier `questions.js` (la première réponse de la liste `a` est la bonne).
